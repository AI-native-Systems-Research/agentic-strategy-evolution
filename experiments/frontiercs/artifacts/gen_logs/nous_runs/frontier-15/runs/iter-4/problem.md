# Problem Framing — Iteration 4

## Research Question

Can extending the BFS-optimal endgame from k=4 to k=5 elements reduce worst-case operation count for prefix-suffix swap sorting while maintaining the maximum judge score of 100?

The mechanism under study is the endgame optimization of the circular buffer rotation sort. The main loop (`solution.cpp`, main loop section) places elements 2..n-k using 2 operations each. The endgame handles the last k elements using BFS-precomputed optimal sequences. Prior iterations confirmed k=2,3,4 all achieve score 100, with worst-case operation counts 2n, 2n-2, 2n-4 respectively.
