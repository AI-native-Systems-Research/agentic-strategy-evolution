## R1 fix: async mismatch (post-review)

Session.connect/turn/disconnect were async but FakeClient had sync
connect/query/interrupt/disconnect and receive_response returned a single
value instead of being an async generator. Tests used anyio.run() for turn
but called connect/disconnect synchronously.

Fixed: FakeClient.connect, query, interrupt, disconnect are now async def.
FakeClient.receive_response is now an async generator (yields each scripted
message). All tests in test_session.py and test_fake_client.py use
async def test methods (pytest-asyncio auto mode). Added signature tests
verifying FakeClient methods are coroutines/async generators. Corrected
progress.txt note about SDK API signatures.
